# Digipoort Connector for Dutch VAT – User Guide

## About this extension

Digipoort Connector for Dutch VAT connects the Dutch electronic VAT declaration in Business Central to Semansys, which delivers declarations to Digipoort of the Belastingdienst. This version contains the **Digipoort Connector Setup**, where an administrator chooses whether the company works with the Digipoort test environment or with the official environment. After an environment copy, and in a company created with **Copy**, the setup is set back to **Acceptation**, the Digipoort test chain, automatically. The extension signs in to Semansys, and every call to Semansys is recorded in **Digipoort Log Entries**. You submit a VAT declaration to Digipoort with one action, in Business Central online without a certificate of your own, and get its Digipoort status when you need it. An assisted setup guides an administrator through the setup of a company.
